# Contributor Guide

- Read `SESSION_HANDOFF.md` at the start of every new session: it is the authoritative technical working memory of the project (decisions, constraints, status, next steps).
- Keep `SESSION_HANDOFF.md` updated whenever decisions, architecture, or implementation state change materially, so a new session can continue with minimal loss of context.
- Keep changes scoped. Do not modify `PROMPT.md`; it is a personal file.
- Commit your changes frequently, even if incomplete, to maintain a clear history of progress.
- Do not stop in the middle of a subtask. Finish it before moving on to the next.
